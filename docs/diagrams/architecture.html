2. コンポーネント詳細

コンポーネント 技術 役割
Cloud Run Python 3.11 + Flask バックエンドAPI、ファイル収集処理
Playwright Chromium (Headless) Carewell Webスクレイピング
Firestore Native Mode (carewell-native) メタデータ永続化
Google Drive Drive API v3 ファイル保存
Google Sheets Sheets API v4 受講生マスタデータ
Dashboard Vue.js 3 + Vite 提出状況可視化
CI/CD GitHub Actions テスト・デプロイ自動化

3. データフロー詳細

sequenceDiagram participant CS as Cloud Scheduler participant CR as Cloud Run participant CW as Carewell Web participant GD as Google Drive participant FS as Firestore participant DB as Dashboard Note over CS,DB: ファイル収集フロー (毎時) CS->>CR: POST /collect-files CR->>CW: Playwright ログイン CW-->>CR: セッション確立 CR->>CW: ファイル一覧取得 CW-->>CR: HTML (学生・ファイル情報) loop 各ファイル CR->>CW: ダウンロード CW-->>CR: ファイルバイナリ CR->>GD: アップロード GD-->>CR: file_id CR->>FS: メタデータ保存 end CR-->>CS: 200 OK (結果) DB->>FS: データ取得 FS-->>DB: 最新データ表示

4. 受講生同期フロー

sequenceDiagram participant CS as Cloud Scheduler participant CR as Cloud Run participant GS as Google Sheets participant FS as Firestore Note over CS,FS: 受講生同期フロー (毎日 JST 02:00) CS->>CR: POST /admin/sync-students-from-sheets CR->>GS: 全シート読み込み GS-->>CR: 受講生データ (全クラス) Note over CR: 重複チェック CR->>CR: student_id 重複検出 CR->>CR: 最初の出現を active に loop 各受講生 CR->>FS: students/{student_id} upsert end Note over CR,FS: Backfill処理 CR->>FS: 全files取得 loop student_idが一致するfile CR->>FS: 非正規化データ更新 end CR-->>CS: 200 OK (同期結果)
