3. スキーマ詳細

3.1 submissions/{class_name}

フィールド 型 説明 例
class_name string (Document ID) クラス名（PK） No1
created_at timestamp 作成日時 2025-11-04T10:00:00Z
last_updated timestamp 最終更新日時 2025-11-30T08:00:00Z

3.2 submissions/{class_name}/tasks/{task_id}

フィールド 型 説明 例
task_id string (Document ID) 課題ID（PK） 課題①
task_pattern string 課題表示名 課題①業務分析　※～11/3〆切
file_count number ファイル数（Atomic Increment） 150
created_at timestamp 作成日時 2025-11-04T10:00:00Z
last_updated timestamp 最終更新日時 2025-11-30T08:00:00Z

3.3 submissions/{class_name}/tasks/{task_id}/files/{composite_key}

フィールド 型 説明 例
composite_key string (Document ID) student_id + filename N3304966_業務分析.pdf
student_id string 日介番号（FK → students） N3304966
student_name string 受講生名（非正規化） 河原 剛次
filename string ファイル名 業務分析.pdf
drive_file_id string Google Drive ファイルID 1abc123...
drive_folder_id string Google Drive フォルダID 1xyz789...
submit_date string 提出日 2025/11/01
grading_info string 採点情報 合格
uploaded_at timestamp アップロード日時 2025-11-04T10:30:00Z

3.4 students/{student_id}

フィールド 型 説明 例
student_id string (Document ID) 日介番号（PK） N3304966
name string 氏名 河原 剛次
furigana string ふりがな かわはら ごうじ
class_name string クラス名 No1
company string 会社名 株式会社ABC
office string 事業所名 東京支店
service_type string サービス種別 入所・居住系
group string グループ A
serial_number string 通し番号 005
student_number string 受講番号 A005
status string 状態 active / inactive
created_at timestamp 作成日時 2025-11-18T02:00:00Z
updated_at timestamp 更新日時 2025-11-30T02:00:00Z

4. インデックス定義

ファイル: firestore.indexes.json

コレクション フィールド 用途
files (collectionGroup) student_id ASC, uploaded_at DESC 受講生別ファイル一覧
students class_name ASC, name ASC クラス別受講生一覧
students status ASC, class_name ASC 有効受講生フィルタ
