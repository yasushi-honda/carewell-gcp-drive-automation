### 2. グループ一覧カードの提出状況表示（PR #48〜#50、後半）
decision-maker の要望「どのグループがどれだけ提出していないのか一目で分かる表示が各グループカードに欲しい」に対応。plan mode + plan-crossreview（grip + codex 2パス）で計画を承認後に実装。

- **PR #48**: 各カードに、提出率のバー + 「提出 N / 未提出 M」+ 合否の内訳（合格・採点待ち・不合格）を表示。複数回提出は「最新の提出の状態」（decision-maker 確定）。合否は完全一致で判定（既存コードの `includes('合格')` は「不合格」にも一致するため流用しない）。名簿外・日介番号が空の提出は集計から除外して警告、取得失敗と0件を区別（障害事例 #15・#17 対策）。分母は active な受講生。BE・Firestore ルール・スキーマの変更なし

- **PR #50**: 本番実測結果を `docs/dashboard-mobile-measurement.md` §5.2 と GOAL.md に記録
