## ⚠️ 重要な用語の使い分け

| 用語 | 単位 | 意味 | 使用例 |
|------|------|------|--------|
| **学生** | 名 (人) | 提出者の人数 | 「150名の学生が提出」 |
| **レポート/提出物** | 件 (個) | 提出された成果物の数 | 「200件のレポートを取得」 |

**なぜ学生数 ≠ レポート数?**
- 1人の学生が複数ファイルを提出 → レポート数 > 学生数
- 提出していない学生がいる → レポート数 < 学生数
- グループ提出 → レポート数 < 学生数

## データ規模の確認方法

### Cloud Run ログから確認

```bash
gcloud logging read "resource.type=cloud_run_revision AND \
  textPayload=~'File collection completed.*submissions_found:'" \
  --limit 10 --format json | \
  jq -r '.[] | select(.textPayload | contains("submissions_found:")) | .textPayload'
```

### 出力例
```
[carewell-№01-課題①] File collection completed: submissions_found: 200, processed: 0, failed: 49, skipped: 151
```

→ **submissions_found: 200** = 200件のレポートを検出
